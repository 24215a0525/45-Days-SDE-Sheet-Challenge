# 🚀 45 Days SDE Sheet Challenge

Welcome to my **45 Days SDE Sheet Challenge** repository!

This repository contains my solutions to the popular **Striver's SDE Sheet** by Take U Forward. The goal of this challenge is to strengthen my Data Structures and Algorithms knowledge, improve problem-solving skills, and prepare for technical interviews.

---

## 🎯 Challenge Goals

* Complete Striver's SDE Sheet
* Improve problem-solving abilities
* Learn optimal approaches and patterns
* Build consistency in coding
* Prepare for placements and coding interviews

For every problem, I try to:

1. Understand the problem statement.
2. Think of the brute-force solution.
3. Optimize the solution.
4. Analyze time and space complexity.
5. Write clean and readable code.
